# ORDER 998-qrwu. THE enclave CA bundle directory — one literal, read by every
# lane.
#
# It was written as a literal in 38 places across 16 files (measured
# 2026-09-03): 8 inside an embedded shell preamble in
# crates/tillandsias-macos-tray/src/diagnose.rs, the rest across the headless
# crate and a dozen scripts. 975-rsgm needs this directory MOVED off /tmp —
# /tmp is volatile, and podman records a bind SOURCE at container creation, so a
# reboot makes the proxy permanently unrestartable. Moving a path written in 38
# places moves some and misses others, and a missed one points at a directory
# that is not there, on a recovery path that only runs when something is already
# wrong.
#
# So the path is declared HERE and nowhere else. Rust reads it with include_str!
# (the manifest travels inside the artifact, the capabilities.txt pattern);
# shell reads it through scripts/lib-ca-path.sh. A drift test asserts the two
# agree, and scripts/check-ca-path-literals.sh ratchets the literal count so it
# cannot grow back.
#
# CHANGING THIS VALUE IS NOT A CONSTANT CHANGE. Existing containers bind the OLD
# path in their stored definitions and must be RECREATED, not restarted — that
# migration is 998-3z6g, and it is why this rung lands first and alone.
# ── THE VALUE, AND WHY IT IS A TEMPLATE (998-3z6g) ──────────────────────────
#
# `${HOME}` is expanded by BOTH readers. It is a template rather than a static
# path because two measurements ruled a static one out:
#
#   GUEST (macbook-macos, real Mac VM, 2026-09-04): /var/lib/tillandsias-ca
#     works — key present, perms 600, owner root, directory survives reboot.
#     It works BECAUSE the guest runs as root.
#   HOST (yoga, same day): uid 1000, rootless. `mkdir -p /var/lib/tillandsias-ca`
#     -> Permission non accordée. /var/lib is not writable AT ALL.
#     Durable and writable here: $HOME/.local/state, $HOME/.local/share.
#
# So /var/lib fails on a rootless host for exactly the reason it succeeds in the
# guest, and /tmp works everywhere and is the bug — volatile by design, cleared
# on reboot and swept by systemd-tmpfiles, which is what made the proxy
# permanently unrestartable (975-rsgm).
#
# A HOME-relative path was the only candidate measured to satisfy both: durable
# on a rootless Linux host, and equally creatable in the guest where HOME=/root.
#
# EXPANSION IS THE READERS' JOB AND MUST AGREE. tillandsias-core::ca_path
# substitutes ${HOME} from the environment; scripts/lib-ca-path.sh gets it from
# the shell. A test asserts the two produce the same string, because a template
# with two expanders is a new way for one declaration to mean two things — which
# is the defect this file was created to remove, not a licence to reintroduce it.
${HOME}/.local/state/tillandsias/ca
