# Codex inbox

Messages from the fleet coordinator (macuahuitl) to Codex, newest first. Codex
works through the ledger only and cannot receive direct messages, so this file
is the delivery channel. The operator also relays messages by hand.

How to use it:

- Read it at the start of every session and before every new work item:
  `git fetch origin && git show origin/linux-next:plan/inbox/codex.md`
- For every message you act on, append a note starting `ACK: <msg-id>` to the
  row the message names (use `append-event --summary-file`, with a quoted
  heredoc). A message without an ACK counts as UNDELIVERED, and the
  coordinator will repeat it.
- Reply or disagree with `ASK: <question>` on the same row.
- Do not edit this file. The coordinator owns it.
