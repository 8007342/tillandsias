### 915-wkm2 criterion 2 — report scratchpad QUOTA headroom, not `df` free space

The scratchpad is tmpfs. systemd sizes `/tmp` at 50% of RAM but a usrquota can sit far below, so
`df` reports gigabytes free while every write returns EDQUOT — the host stays healthy and only
the agent's tooling dies. It presents as *"my shell is broken"*, not *"I filled a disk"*, which is
how it wedged macuahuitl for several cycles.

**The threshold is absolute, and the two hosts' numbers are why a percentage would have been
exactly wrong:**

```
lenovinha   1620M of  5525M =  29% used -> WARN (3.9 GiB, cannot build)
macuahuitl 15900M of 25564M =  62% used -> ok   (9.6 GiB, can build)
```

A *"warn above N%"* rule **passes the host that will wedge and warns the one that will not.** The
bar is what the work costs — one cold Rust `target/` at 2.6–4.4 GB — overridable per host. That
inversion is a fixture arm, not a comment.

Advisory, exits 0 on every path, asserted twice. Gating a cycle on a capacity condition is the
888-miiy shape.

Live here it already earns its keep: `warn:scratchpad-headroom-low:3905m-of-5525m`, with
`NOTE: df reports 5286M free, which OVERSTATES what you can use.`

`/run/user/1000` and `/tmp` **all** report as `tmpfs`, so parsing by device name picks an
arbitrary mount and only one is the scratchpad.

### Two fixture bugs of my own, both caught before landing

- **The no-quota arms found the system `quota`.** Omitting my stub does not hide `/usr/bin/quota` —
  prepending a bin dir cannot mask a system binary — so those arms silently tested the *with*-quota
  path and returned `skip:no-quota` instead of the disk verdict. Same trap as masking jq two cycles
  ago. Fixed with a curated PATH whose absence of `quota` is **asserted** as a precondition.
- **I asserted the percentage point backwards**, claiming the warned host was *fuller* by percent.
  It is emptier — 29% against 62% — which is the stronger form and the one that actually shows a
  percentage rule inverting both verdicts. The arm failing is how I found out; written loosely it
  would have passed while asserting something false.
