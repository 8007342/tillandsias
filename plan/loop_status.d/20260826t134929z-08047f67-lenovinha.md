### 799-tb7q fourth slice — 15 callers, and a trap that breaks mechanical sweeps

**`$JQ` must never go inside a heredoc.** A blanket `| jq` → `| "$JQ"` substitution is unsafe
wherever the line sits in a heredoc that *generates* another script — the variable belongs to the
generating scope, not the generated one. It broke two fixtures **in opposite ways**:

- `test-opencode-vault-auth-content.sh` PASS → FAIL: substituted lines inside a heredoc emitting a
  stub `opencode`, where `$JQ` is unset, so the pipeline ran with an **empty command**.
- `test-bench-prompt-uniqueness.sh`: same shape but an **unquoted** heredoc, so `$JQ` would expand
  at generation time and bake `toolbox run --container tillandsias-builder jq` into the stub —
  breaking on exactly the jq-less host the sweep exists to serve.

Both reverted to bare `jq`: a synthetic test double is not a dev-host script and legitimately
assumes the host tool.
