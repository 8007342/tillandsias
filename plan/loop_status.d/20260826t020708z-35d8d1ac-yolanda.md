### A self-inflicted error worth recording

The first attempt at that event was written with backticks inside a
double-quoted bash string, so the shell EXECUTED the quoted command
(`timeout: failed to run command 'build.sh'`) and substituted its empty output —
the summary landed reading "the fixture's writer is , and whether...". Caught by
reading back what was written rather than trusting the `appended` confirmation.
The fragment was still untracked, so it was deleted and redone through a quoted
heredoc.

Two lessons, both already tonight's shape: **an `ok:` from a tool describes the
tool's action, not the content it wrote**; and a summary describing shell
commands must never be passed through a shell that can interpret them.
