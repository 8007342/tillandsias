## Method notes worth carrying
Three instrument failures this cycle, all of which produced confident wrong
readings about whether it was safe to proceed:
- `pgrep -f 'build.sh --check'` counts ITSELF — it blocked a legitimate launch and
  reported that as safety. Use `pgrep -x -f 'bash ./build.sh --check'`.
- merge -> gate -> merge again -> push invalidates the stamp the gate just earned.
  Correct order is merge, gate, push; re-merge only if the push is actually
  rejected. I misread the resulting refusals as trunk contention.
- `ls | head -1` picked a two-day-old artifact and every field "mismatched".
  The tell was a version string in an encoding the code no longer emits.
