## Cycle - windows (windows-next)

- Closed 723-2yb3, rung 2 of 3. CAP_PTY_HEARTBEAT_V2 negotiated end to end; the
  heartbeat carries the guest's input state instead of only proving the wire is
  alive.
- A NEW trailing ControlMessage variant, not a sentinel stuffed into the
  existing empty PtyData: a payload in `bytes` would be printed as terminal
  output by a v1 host, so the frame had to be one a v1 host REFUSES rather than
  misreads. It refuses it as Error::UnknownVariant, which is why negotiation is
  load-bearing and not decorative.
- v1 and v2 are checked as INDEPENDENT capability tokens, not a version ladder.
  A peer may advertise v2 alone, and treating either as implying the other is
  how a negotiation grows a case nobody tests.
- Reporting only, on purpose: the host names the state in its waiting report and
  changes no control flow. Acting on it is rung 3 (723-g4bk). Shipping the
  observation first makes the wedge legible now without touching deadline
  semantics, and lets rung 3 be judged on its own.
- vsock_exec 19 passed including the four-combination matrix (v1 guest + v2
  host, v2 for all three states, and a guest MIXING shapes mid-session - what a
  rolling upgrade actually produces) driven from ONE shared fake guest so the
  combinations cannot drift into different tests. Both order-332 pins untouched
  and green. tillandsias-headless 28 passed with the v1 heartbeat shape pinned
  unchanged.
- Negative controls: NotBlocked and Unknown must never claim blockage, and
  Unknown must stay distinguishable from working - without them a report that
  said "blocked" every time would pass the positive assertion while restoring
  the ambiguity this rung removes.
