### A hazard class jq does not have

**openssl writes files.** jq is a pure filter — stdin in, stdout out, namespace-agnostic — so a
toolbox fallback is transparent. openssl generates a CA cert *into a directory*, so the fallback
only works where the container shares the write path. Otherwise the cert lands where the caller
cannot find it: a **silent** break, not an error.

Measured rather than assumed: `/tmp` is shared bidirectionally with the toolbox (host-written file
readable inside, and vice versa), and all three `CERTS_DIR` values are under `/tmp`. A fixture arm
now fails if any starts writing elsewhere — mutation-tested by pointing one at `/var/lib`.

That makes three distinct hazard classes this sweep has surfaced, none visible from the packet's
original framing: **exclusion classes** (curl-piped installers, bootstrap wrappers, shipped
diagnostics), **heredoc scope**, and now **write-path namespace**.
