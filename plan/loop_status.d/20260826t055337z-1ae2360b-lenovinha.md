Continued my own 2026-08-24 state on this packet. It left exactly one thing blocking the
~50-script sweep: the shipped diagnostics run where no builder toolbox exists and needed a
different answer, **decided before sweeping**. Decided and implemented.

**The decision: a diagnostic must always produce its DATA. Only the PRESENTATION may degrade. And
a missing parser must never be reported as a fault of the thing under diagnosis.**

Both scripts exited 1 with "brew install jq" — telling an end user to install a developer tool,
and (the expensive half) collapsing "the tray is broken" and "I have no parser" into one verdict,
since exit 1 was documented as *"could not locate or invoke tillandsias-tray, or jq missing"*. You
run a diagnostic precisely when something is already wrong, which makes a misattributed verdict
costlier here than anywhere else in the tree.

Dispatch is host jq → toolbox jq → degrade. The degrade prints the **raw** tray output and exits 3,
distinct from 1, saying outright it is not a tray fault. **No second JSON parser, deliberately** —
two parsers that can disagree is a misattribution generator, and a diagnostic is the last place for
one.
