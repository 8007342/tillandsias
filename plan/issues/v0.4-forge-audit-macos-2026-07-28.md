## 1. macOS Tray Icon — Missing Graphics (GAP)

### Finding
The macOS tray icon falls back to a static letter `"T"` because the baked-in
`tray-icon.png` is absent from the installed `.app` bundle. Even when present,
the macOS tray uses a single static PNG — it has **zero state awareness**.

### Linux Reference
The Linux tray (`crates/tillandsias-headless/src/tray/mod.rs`) has a full
plant-lifecycle icon state machine:

| State | SVG Genus | Meaning |
|-------|-----------|---------|
| Pup | ionantha/pup | Launching / initializing |
| Mature | ionantha/bud | At rest, healthy |
| Building | ionantha/bloom | Image/container build in progress |
| Blooming | ionantha/bloom | Build complete, awaiting ack |
| Dried | ionantha/dried | Unrecoverable error |
| Stopping | ionantha/dried | App shutting down |

- 72 SVGs across 24 plant genera, rendered to PNG at build time via `resvg`
- Embedded via `include_bytes!` — no runtime filesystem I/O
- D-Bus `new_icon` signal emits on every state transition
- Click-to-acknowledge: `Blooming → Mature` on user click

### macOS Implementation
- **File**: `crates/tillandsias-macos-tray/src/status_item.rs:136-181`
- Single `tray-icon.png` loaded from `.app/Contents/Resources/`
- `setTemplate(true)` for light/dark mode tinting
- Fallback: `button.setTitle("T")` when PNG missing
- **No state machine, no lifecycle awareness, no animation**

### Windows Reference
Windows (`crates/tillandsias-windows-tray/src/notify_icon.rs`) also uses a
single static `.ico` resource — same gap as macOS (no state machine).

### Impact
End users see an unchanging `"T"` letter in the menu bar regardless of whether
the forge is building containers, healthy, or stalled. Contrast: Linux users
see a sprout grow, bloom, and wither — the icon is a live status indicator.

### Recommendation
File as **order 465** (v0.5): macOS tray icon state machine parity.
Port the Linux plant-lifecycle SVG pipeline to macOS using `NSImage` from
embedded PNG data (or render via `resvg` at build time into a multi-representation
`NSImage`). Same for Windows.
