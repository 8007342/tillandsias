# Third-party licence: demucs-weights-unstated

@trace spec:third-party-licence-demucs-weights-unstated

## Purpose

This project depends on adefossez/HTDemucs and adefossez/HTDemucs-6s and must now adhere to attribution, non-commercial and review, the obligations its licence `demucs-weights-unstated` carries. The acknowledgement that accepted the licence is under `licences/acknowledgements/`, signed with an OS-verified key and committed with this spec. Tillandsias records these obligations; honouring them over the project's lifetime is the project's own work, and each requirement below says how.

## Requirements

### Requirement: Attribution
<!-- req-id: 2453acd0 -->

The project SHALL show the attribution "Demucs, Alexandre Défossez" wherever it credits the work it is built on, for as long as it depends on adefossez/HTDemucs and adefossez/HTDemucs-6s.

The licence says, verbatim: "The 6 source variant of htdemucs was trained only on Meta internal dataset, which likely means CC-NC-BY license is applicable, as it was the case for all models released by FAIR."

How this project honours it: _to be written by the project owner; for example "the credits screen shows 'CorridorKey'"._

#### Scenario: The project credits the work
- **WHEN** the project shows its credits
- **THEN** "Demucs, Alexandre Défossez" is among them
