# WHAT ./build.sh --ci-full RUNS THAT ./build.sh --check DOES NOT.   ORDER 1087-h2z9
#
# Every host lands through --check. --ci-full runs about once a day. So a check
# that lives only in the second is one a landing host cannot see, and a day of
# green landings accumulates whatever it would have caught. On 2026-09-06 that
# was NINE reds on a trunk where --check was green on all nine.
#
# This file is the list that did not exist. It is DATA, read by
# scripts/test-gate-divergence-is-declared.sh, which fails when a difference
# appears that is not listed here. Adding a line is how you declare one.
#
# FORMAT:  <path>  <class>  <reason>
#
# CLASSES:
#   infra      not a check — a library, builder, runner or reporter. Its absence
#              from --check is not a coverage gap.
#   excluded   deliberately absent, WITH the reason. The worked example is the
#              litmus suite (build.sh:2252, order 748-tkjx): minutes long, and a
#              gate that slow gets bypassed with --no-verify. That reasoning is
#              sound and is not to be reversed.
#   untriaged  present in --ci-full, absent from --check, and NOBODY DECIDED.
#              This is the debt. The fixture ratchets it: the count may fall,
#              never rise. Do not clear one by inventing a reason — either wire
#              it into --check or write down why it stays out.
#
# WHY A RATCHET RATHER THAN A HARD RED: 22 untriaged entries on the day this was
# written. A gate that reds trunk on day one gets switched off, which is the
# failure the scorable-obligation guard's own header names. The ratchet makes the
# debt visible and bounded without making the gate unsatisfiable.
